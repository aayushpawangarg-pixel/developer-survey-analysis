# 📊 Stack Overflow Developer Survey Analysis

Exploratory data analysis of the Stack Overflow Developer Survey using Python and Pandas.

## 🔎 What I'm Exploring

This project explores questions about developers, their experience, learning journey, and technology preferences.

Some of the questions I'm investigating:

- How many respondents are professional developers?
- How many are still learning to code?
- How does developer status vary across age groups?
- Which programming languages and technologies are commonly used?
- What patterns can we find in the developer community?

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
